# ALBUM CHART LIST: one release per line.
#
# Format (everything after the link is optional, in any order, separated by |):
#
#   LINK | type | artist=Name, Name | feat=Name, Name | title=Name
#
#   type    album, ep, compilation, playlist or single. Say it as a bare word
#           ("ep") or as type=ep. It works with ANY kind of link, so a Suno
#           playlist link can be shown as an album, EP, compilation, etc.
#           If you leave it out, it follows the link (album link = Album,
#           playlist link = Playlist).
#   artist= the main artist(s), separated by commas. Use  artist=Various Artists
#           (or just the bare word "various") for a various-artists release.
#           If you leave it out, it's worked out from the songs: one artist on
#           every song = that artist, more than one = Various Artists.
#   feat=   featured artists, separated by commas. (You can also write
#           artist=Tÿler ft. Alice, Bob  and it splits them for you.)
#   title=  only needed if the album's name doesn't show up on its own.
#
# Examples (remove the # to use):
#   https://suno.com/album/e0bb91fe-b943-46a9-91b4-04d06ac9ec98 | album | artist=Tÿler | feat=Alice, Bob
#   https://suno.com/playlist/f3d29afd-7119-4712-8105-bfadc43516fd | ep | artist=Tÿler
#   https://suno.com/playlist/9f1c2b97-0a47-42fa-8769-593ec2b76ef7 | compilation | various
#
# A # starts a comment (anything after it on a line is ignored).
# Each album ranks by plays gained across its songs since the last snapshot.
